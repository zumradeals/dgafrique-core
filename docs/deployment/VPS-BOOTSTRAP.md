# Préparation VPS — aperçu

Le déploiement final sera généré après création du socle Laravel et audit des conventions déjà utilisées par GAMAD Core/GamaDrive.

Pré-requis attendus :

- Ubuntu 24.04 LTS ;
- Nginx ;
- PHP 8.4 avec extensions Laravel/PostgreSQL ;
- Composer 2 ;
- PostgreSQL ;
- Redis ;
- Node.js LTS pour compiler Tailwind/Vite ;
- Supervisor ;
- certificat TLS.

Ne pas encore pointer `dgafrique.com` vers cette application. Utiliser un domaine de préproduction et conserver un plan de retour arrière jusqu'à validation des parcours prioritaires.
