# Réseau ZUMRA - pointeur canonique

La définition et les règles du Programme ZUMRA sont désormais fixées par :

[`docs/canon/ZUMRA-DOCTRINE-INVARIANTE.md`](../canon/ZUMRA-DOCTRINE-INVARIANTE.md)

Ce document historique a été neutralisé le 14 août 2026 parce qu'il contenait
des hypothèses antérieures depuis rejetées, notamment :

- le créateur automatiquement premier responsable ;
- l'entrée dans une ZUMRA uniquement par invitation ;
- l'activation définie seulement par cinq membres ;
- un état de retard appliqué à une contribution facultative.

Le canon prévaut sur toute ancienne note, maquette ou implémentation. L'historique
Git conserve les versions précédentes pour audit, mais elles ne doivent plus guider
la conception ou le développement.
