# Charte graphique initiale — GamaDigit

## Logo V1

Le symbole représente un **G ouvert** orienté vers l’avant, accompagné de pixels qui suggèrent la transformation numérique, la modularité et l’évolution.

Le logo est disponible dans :

- `public/brand/gamadigit-mark.svg` ;
- `public/brand/gamadigit-logo.svg` ;
- `public/favicon.svg`.

Cette version est le point de départ officiel de la V1. Elle pourra être raffinée sans modifier le concept central.

## Palette

| Rôle | Couleur | Valeur |
|---|---|---|
| Bleu nuit | Confiance, structure, fonds | `#061F35` |
| Bleu océan | Technologie, liens, actions | `#0877C9` |
| Cyan | Innovation, accent principal | `#19C2D0` |

| Nuage | Fonds secondaires | `#F4F8FB` |

## Typographie

La V1 utilise une pile système pour garantir rapidité, lisibilité et stabilité. Les titres sont très gras, les textes sont simples et aérés.

## Ton visuel

- professionnel sans être froid ;
- moderne sans effets excessifs ;
- accessible aux non-techniciens ;
- cartes arrondies et espaces généreux ;
- appels à l’action directs ;
- contraste fort et expérience mobile prioritaire.
