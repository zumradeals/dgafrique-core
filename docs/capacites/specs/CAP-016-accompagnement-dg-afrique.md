# CAP-016 — Accompagnement DG Afrique

- **Domaine :** Projects & Satellites
- **Propriétaire d’exécution :** DG Afrique
- **Statut :** implémenté — preuve VPS requise
- **Sources :** CAP-014, CAP-015 ; référentiel canonique CAP-016
- **Frontière suivante :** CAP-017 porte la maturité ; CAP-045/046 détailleront plus tard la file de demandes et le dossier d’accompagnement enrichi.

## Finalité

Permettre à DG Afrique d’aider un projet à franchir certaines étapes de développement en apportant ou en coordonnant des appuis utiles.

> Accompagner signifie renforcer la capacité d’agir du projet. Cela ne donne à DG Afrique ni propriété, ni contrôle, ni pouvoir de décision sur le projet.

## Activation

Le porteur autorisé du projet active explicitement l’accompagnement. Il peut également le terminer et le reprendre plus tard. Cette activation n’altère aucun champ de propriété, de portage, de maturité ou de statut juridique du projet.

## Interventions

Une intervention est un fait traçable rattaché à un accompagnement actif. Les catégories initiales couvrent le contrat canonique :

- orientation ;
- expertise ;
- formation ;
- appui numérique ;
- mise en relation ;
- structuration ;
- partenaires ;
- orientation vers un mécanisme de financement.

L’intervention peut être fournie directement par DG Afrique ou coordonnée avec un partenaire identifié. Les catégories disponibles sont administrables sans redéploiement.

## Traçabilité

Chaque intervention conserve :

- sa catégorie ;
- son origine interne ou partenaire ;
- l’intervenant ou partenaire affiché ;
- un résumé factuel ;
- une prochaine étape facultative ;
- la date de l’action ;
- l’identité Core de l’administrateur ayant enregistré le fait.

Les actions enregistrées ne sont ni réécrites ni supprimées dans ce lot. L’activation, la fin d’accompagnement et chaque intervention alimentent aussi le journal d’événements du projet.

## Frontières

- aucune modification automatique du propriétaire, du régime de propriété ou du décideur du projet ;
- aucune création automatique de membre, d’équipe ou de responsabilité ;
- aucune maturité calculée ou imposée : CAP-017 reste distinct ;
- aucune file détaillée de demandes, notation ou workflow d’incubation lourd : CAP-045/046 restent distincts ;
- aucune transaction financière, collecte, promesse de financement ou écriture comptable ;
- une intervention de type financement signifie uniquement orientation ou coordination vers un dispositif disponible.

## Critères de preuve

- activation et fin réservées au porteur autorisé ;
- accompagnement progressif réactivable sans perte d’historique ;
- interventions internes et partenaires représentables ;
- chaque action est traçable dans sa chronologie et dans les événements projet ;
- un administrateur non provisionné ne peut pas enregistrer une intervention ;
- configuration des catégories sans redéploiement ;
- aucune mutation de propriété, contrôle ou maturité ;
- aucune table ou écriture financière créée par CAP-016 ;
- migration, tests, build et HTTPS verts sur VPS.
