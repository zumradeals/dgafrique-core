# Preuve CAP-002A — Connexion d'un Compte GAMAD existant

## Décision

**LOT A VALIDÉ PRÉPRODUCTION le 2026-08-13.**

Cette décision couvre la connexion, la session portail, l'accès à Mon espace et
la déconnexion d'un Compte GAMAD existant. Elle ne valide pas encore le lot B de
création et de vérification d'un nouveau compte.

## Environnement éprouvé

- branche : `foundation/laravel-portal` ;
- commit déployé : `ff9c5a3` ;
- URL : `https://beta.dgafrique.com` ;
- runtime : PHP 8.4, Laravel 13, Redis, Nginx, VPS GAMAD ;
- autorité d'identité : GAMAD Core ;
- produit raccordé : `PRD-GAMAD-005`.

Aucun secret, mot de passe, bearer ou libellé personnel exact n'est reproduit
dans ce dossier.

## Preuve automatisée

Commande exécutée sur le VPS :

```bash
php8.4 artisan test
```

Résultat observé : **29 tests réussis, 65 assertions, 0 échec**, couvrant
notamment :

- connexion et résolution de l'identité canonique ;
- session portail et accès à `/espace` ;
- destruction de la session après un `401` Core ;
- conservation de la session et réponse `503` lors d'une panne transitoire ;
- rejet des destinations externes ou ambiguës ;
- révocation Core et destruction locale à la déconnexion ;
- absence du moyen d'accès dans le flash de session ;
- limitation des tentatives par IP sans guard Laravel local.

## Preuve réelle navigateur

Une connexion réelle a été effectuée sur `https://beta.dgafrique.com/connexion`.
Le résultat observé dans Mon espace confirme :

| Contrôle | Verdict |
|---|---|
| Compte GAMAD accepté par Core | oui |
| Session annoncée active | oui |
| Identité canonique affichée | oui, référence personnelle non recopiée ici |
| Libellé retourné par Core affiché | oui, non recopié ici |
| Programme ZUMRA déduit automatiquement | non |
| Déconnexion proposée | oui |
| CAP-003 présenté comme non encore actif | oui |

## Preuve HTTP et infrastructure

- extension PHP Redis présente ;
- `npm ci` : 0 vulnérabilité signalée ;
- production Vite compilée avec succès ;
- `/connexion` : **HTTP 200** ;
- `/espace` sans session : **HTTP 302** vers
  `/connexion?next=%2Fespace` ;
- cookie portail observé avec `Secure`, `HttpOnly` et `SameSite=Lax`.

## Invariants confirmés

1. GAMAD Core reste l'unique autorité d'identité membre.
2. DG Afrique ne stocke aucun mot de passe membre.
3. Le bearer est chiffré avant son stockage dans la session Redis chiffrée.
4. Un rejet Core détruit la session ; une panne transitoire ne la détruit pas.
5. Le Compte DG Afrique gratuit n'entraîne aucune adhésion ZUMRA.
6. Aucun rôle métier ou statut ZUMRA n'est inventé dans la session.

## Gate restant

**CAP-002B — création et vérification gratuite reste à spécifier et éprouver à
partir des contrats GAMAD Core.** CAP-003 à CAP-084 restent bloqués jusque-là.
