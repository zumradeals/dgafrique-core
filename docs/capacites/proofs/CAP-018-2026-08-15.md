## Contrat validé

CAP-018 est implémenté comme un parcours préparatoire vers une autonomie organisationnelle plus forte. Il ne crée pas encore de satellite, d’organisation canonique ou d’identité organisationnelle.

Le parcours :

- identifie comme éligibles les projets aux repères `POTENTIAL_STRUCTURE` ou `POTENTIAL_SATELLITE` ;
- permet au porteur habilité d’ouvrir un parcours vers une forme envisagée : entreprise, association, coopérative, startup, plateforme ou autre forme pertinente ;
- permet de fermer puis rouvrir ce parcours avec traçabilité append-only ;
- rend les projets mûrs observables dans une file d’administration ;
- conserve la possibilité d’un accompagnement DG Afrique sans transférer le contrôle du projet ;
- n’effectue aucun appel de création d’organisation au Core.
