# Preuve CAP-002B — Création et vérification d'un Compte DG Afrique

## Décision

**VALIDÉ PRÉPRODUCTION le 2026-08-13.**

Cette preuve complète CAP-002A et valide le parcours e-mail de création gratuite,
de vérification puis de première connexion. Le canal téléphone n'est pas validé
par ricochet et reste soumis à une preuve de livraison SMS distincte.

## Environnement éprouvé

- branche : `foundation/laravel-portal` ;
- commit applicatif déployé : `a57333a` ;
- URL : `https://beta.dgafrique.com` ;
- runtime : PHP 8.4, Laravel 13, Redis, Nginx, VPS GAMAD ;
- autorité de création et vérification : GAMAD Core ;
- produit raccordé : `PRD-GAMAD-005`.

Aucun e-mail, mot de passe, code à usage unique, bearer ou référence personnelle
exacte n'est reproduit dans ce dossier.

## Preuve automatisée

Commande exécutée sur le VPS :

```bash
php8.4 artisan test
```

Résultat observé : **33 tests réussis, 89 assertions, 0 échec**, couvrant :

- création sous session produit éphémère ;
- dossier de vérification borné sans mot de passe ni code ;
- consommation d'un code valide ;
- conservation de la reprise après refus du code ;
- conservation des références après échec de livraison ;
- régression complète de CAP-001 et CAP-002A.

Le build Vite a réussi et `npm audit` n'a signalé aucune vulnérabilité.

## Preuve réelle navigateur et e-mail

Un nouveau compte a été créé avec une adresse ne possédant pas encore de Compte
GAMAD. Les contrôles suivants ont été observés :

| Contrôle | Verdict |
|---|---|
| Formulaire public de création disponible | oui |
| Code à six chiffres reçu par e-mail | oui |
| Code accepté par GAMAD Core | oui |
| Retour vers la connexion après vérification | oui |
| Première connexion avec le nouveau compte | oui |
| Nouvelle identité canonique affichée dans Mon espace | oui, valeur non recopiée |
| Session membre active | oui |
| Adhésion ZUMRA créée automatiquement | non |

## Preuve HTTP et sécurité

- `/creer-un-compte` : **HTTP 200** ;
- `/verifier-le-compte` sans reprise : **HTTP 302** vers la création ;
- cookie portail : `Secure`, `HttpOnly`, `SameSite=Lax` ;
- mot de passe et code exclus du flash Laravel ;
- session produit révoquée après chaque opération ;
- seules les références Core, le canal, la destination et l'échéance sont
  conservés dans la session Redis chiffrée pendant la vérification.
